# Mission Mavericks × ClaimShield+ Presentation

## 1. PROJECT OVERVIEW

This project is a website-based presentation replacing a traditional PowerPoint deck.

The website must behave like a presentation/keynote experience rather than a conventional scrolling website.

The presentation contains exactly 9 slides.

Only one slide should be visible at a time.

The experience should feel:

- Cinematic
- Colorful
- Flashy
- Modern
- Interactive
- Presentation-driven
- High-energy
- Premium
- Professional

The goal is to present the Mission Mavericks team's ClaimShield+ solution as a polished product/innovation showcase.

# 5. EYE / PRESENTATION MODE

This feature is mandatory.

Every slide must contain a fixed Eye icon in the top-right corner.

Default state:

Navigation is visible.

When the Eye icon is clicked:

Hide:

- Main Navbar
- Progress indicator
- Previous button
- Next button

The Eye icon itself must remain visible.

When clicked again:

Show all navigation.

Use:

- Eye icon when navigation is visible
- EyeOff icon when navigation is hidden

Animation duration:

300–500ms.

The state must persist while navigating between slides.

Example:

User hides navigation on Slide 2.

User moves to Slide 3.

Navigation remains hidden.

User clicks Eye icon.

Navigation becomes visible again.

Use centralized React state or React Context.

Do not duplicate Eye Mode state across slides.
